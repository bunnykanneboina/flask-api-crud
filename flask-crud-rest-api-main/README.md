# Flask CRUD REST API

A simple CRUD REST API built using **Python Flask**, **SQLAlchemy**, **PostgreSQL**, and **Docker**.

## 🚀 Features

- Create a user
- Get all users
- Get a user by ID
- Update a user
- Delete a user
- PostgreSQL database integration
- Docker and Docker Compose support
- RESTful API endpoints

## 🛠️ Technologies Used

- Python
- Flask
- Flask-SQLAlchemy
- PostgreSQL
- Docker
- Docker Compose
- Postman
